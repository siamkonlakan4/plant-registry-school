# API

Public logical routes via JSONP `?path=/public/plants&callback=plantcb_<32 hex>`: `/public/settings`, `/public/plants`, `/public/plants/:id`, `/public/filters`, `/public/stats`, `/public/templates/:id/preview`. `GET /public/plants` รับ q/family/habit/location/page/pageSize และคืนเฉพาะ published. Response `callback({"success":true,"data":[],"meta":{}})`.

Protected calls occur inside Apps Script HTML Service: `google.script.run.adminCall(path,payload)`. Every call independently verifies Workspace active email and Users role. Examples: `/me`, `/me/settings`, `/me/plants`, `/me/plant` `{id}`; `/plants` create `{plant_code,common_name,scientific_name,family,habit,key_features,location,quantity,images:[{name,mime,data}]}`; `/plants/:id` update; `/plants/:id/delete` soft delete; `/plants/:id/images` upload; `/plants/:id/images/:fileId` remove; `/plants/:id/generate-qr`; `/admin/users` list/create; `/admin/users/:id` update and `/delete`; `/admin/settings` read/update; `/admin/templates` list/create; `/admin/templates/:id` update and `/delete`; `/admin/labels/batch-preview`; `/admin/labels/print-log`; `/admin/media`; `/admin/activity-log`; `/admin/plants/export`. `doPost` also routes protected requests but requires the same server-side Session+Users checks; browser role/email are ignored. Success `{success:true,data:{},meta:{at:"..."}}`; error `{success:false,error:{code:"...",message:"..."}}`.
