# ตั้งค่า Google Workspace โดยไม่ใช้ Google Cloud Console

ใช้บัญชีเจ้าของระบบในโดเมนเดียวกับเจ้าหน้าที่. สร้าง Apps Script project ที่ script.google.com, เพิ่มไฟล์ apps-script ทุกไฟล์, ใส่ Script Properties `ADMIN_EMAIL`, `ADMIN_NAME`, `STAFF_DOMAIN`, `FRONTEND_URL`, รัน `bootstrapSystem()` แล้ว `seedDemoData()` ด้วยเจ้าของบัญชี. Deploy Web app สองรายการ: Public = Execute as Me / Anyone, Admin = Execute as Me / Anyone within domain. เจ้าหน้าที่เปิด Admin URL พร้อม `?admin=1`. Session active email ต้องอ่านได้และตรงกับโดเมน+Users Sheet ทุกคำขอ. `Session.getEffectiveUser()` ไม่ใช้เป็นตัวระบุผู้เข้าชม เพราะโหมด Execute as Me จะได้บัญชีเจ้าของเสมอ. ทดสอบอีเมลของ staff จริง; ถ้าว่าง ระบบปฏิเสธและต้องเลือกสถาปัตยกรรมยืนยันตัวตนอื่น. ไม่ต้องสร้าง OAuth Client ID หรือผูกบัตรเครดิต.
